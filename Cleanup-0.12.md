# Studio cleanup 0.12.X

Root services and direct workspace paths are the operating model.

## 0.12.3

Terminal stop, timeout, output limits and run cleanup retire the original process group with bounded, PID-bound TERM/KILL signals. PTY commands retain one session identity and completed handles report cleanup confirmation.

## 0.12.4

Native arguments translate only declared path positions. Git messages, package titles, JSON and shell text remain literal; package payloads translate their source path separately from destination and type.

## 0.12.5

Project and skill helpers decode UTF-8 incrementally across stdout chunks and enforce their response budget in received bytes. Fragmented non-ASCII names and text survive unchanged.

## 0.12.6

Owner retirement stops the current MCP controller even when an older end receipt exists. Controller PID, birth and invocation bind new receipts; previous end bytes remain archived and unresolved effects remain blocked.

## 0.12.7

Ordinary workspace file tools prepare only file paths, run caches and the standalone patch utility. SDK roots and terminal compiler environments resolve the pinned SDK lazily, once per run.

## 0.12.8

Update status uses one completion-driven read at a time. Mutation generations reject older reads, idle polling slows to 30 seconds, hidden tabs stop polling, and progress, reconnect and manual refresh stay responsive.

## 0.12.9

Skill options, freezing and workspace metadata use one catalog snapshot per operation. Script bindings and resource views share verified revision metadata during preparation; later admissions and tombstones are checked afresh.

## 0.12.10

Context reporting returns the estimate and encoded size from the same prepared request. Compaction decisions reuse that pair within the operation and recompute after input or checkpoint changes.

## 0.12.11

Streaming text budgets count only new JSON string content and evict pending tail fragments incrementally. Public deltas retain bounded immutable snapshots and serialize complete projections at flush; original model history stays separate.

## 0.12.12

## 0.12.13
