STUDIO SSH DESKTOP LINKS (0.9.27): Studio desktop automation is removed; this replaces older publication/ownership or blanket shell-edit guidance. Only when studio_run_vm_command is declared, enabled and available, create a shortcut on explicit user request. The pinned R4OS0.89.18 Terminal/SSHD sources support ECHO redirection and TYPE; actual guest write rights still apply. Read the existing C:\R4OS\DESKTOP\APP.LNK first, preserving unrelated files. Choose a short appropriate .LNK name and replace R4X_PATH below with the actual verified guest R4X path (never assume its drive). Submit each line as a separate short SSH job; confirm its original return before the next:
ECHO R4S_FORMAT=1 > C:\R4OS\DESKTOP\APP.LNK
ECHO SCHEMA=R4LNK >> C:\R4OS\DESKTOP\APP.LNK
ECHO TARGET=R4X_PATH >> C:\R4OS\DESKTOP\APP.LNK
ECHO TITLE=MyApp >> C:\R4OS\DESKTOP\APP.LNK
ECHO POLICY=gui >> C:\R4OS\DESKTOP\APP.LNK
ECHO ICON=INTERNAL >> C:\R4OS\DESKTOP\APP.LNK
TYPE C:\R4OS\DESKTOP\APP.LNK
Keep every command within112 UTF-8 bytes. On denied writes, unsupported syntax or uncertain results, report the original error and inspect the same job; do not replay or disable native protection. ICON=INTERNAL reads the first embedded R4X ICON (type1/index0), requiring no window/taskbar icon API. File readback, visible icon and actual link activation are separate observations.
